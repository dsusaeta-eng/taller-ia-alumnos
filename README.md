# Taller: Del Excel a la IA que trabaja para ti

**Prof. Daniel Susaeta** · IDE Business School

Material para los alumnos del taller práctico de IA para empresarios: VS Code con una IA de frontera, más una IA local en LM Studio, trabajando sobre los precios del S&P 500 (2014-2017).

## Antes del taller: prepara tu equipo (obligatorio)

**[Descargar la guía de preparación (guia_preparacion.html)](https://github.com/dsusaeta-eng/taller-ia-alumnos/releases/latest/download/guia_preparacion.html)**: ábrela con doble clic. No pide clave.

En el taller no se instala nada. Antes de venir deja funcionando:

1. **Tu IA local:** LM Studio (u Ollama, en Mac con Intel o PC antiguos) con un modelo adecuado a tu equipo y el servidor encendido. La guía tiene un recomendador para elegirlo.
2. **Visual Studio Code**, con la extensión Python. No necesita cuenta.
3. **Tu IA de frontera** dentro de VS Code, con sesión iniciada: Claude Code (plan Pro) o Codex (cuenta de ChatGPT) recomendadas; GitHub Copilot, con cautela.
4. **Python 3.12 o superior.**
5. **La prueba final** de la guía, con el veredicto **APTO PARA EL TALLER**. Trae la captura.

## Descarga del material (el día del taller)

**[Descargar el material del taller (taller-ia-alumnos.zip)](https://github.com/dsusaeta-eng/taller-ia-alumnos/releases/latest/download/taller-ia-alumnos.zip)**

No necesitas cuenta de GitHub. El enlace siempre entrega la versión más reciente.

**El zip pide una clave.** Es la suma de dos partes: la **parte fija** que recibiste al inscribirte y la **parte del día**, que Daniel da en clase. Por ejemplo, `FIJA` + `AB12` se escribe `FIJAAB12`. La parte del día cambia cada medianoche (hora de Ecuador).

## Cómo empezar

1. Descomprime el paquete en el **disco local** (por ejemplo en Documentos). No lo pongas en Google Drive, OneDrive, iCloud ni Dropbox.
2. Descomprime `taller-ia.zip` **al lado de** `mi-taller`, nunca dentro de ella.
3. Empieza por la guía previa: abre `taller-ia/guia_fundamentos.html` con doble clic. Explica cómo funciona la IA por dentro, con simulaciones para jugar.
4. Para el taller práctico, abre `taller-ia/guia_taller.html` y síguela paso a paso. Las dos guías funcionan sin internet.
5. En VS Code abre **solo** la carpeta `mi-taller`.

Todo lo necesario ya lo traes preparado con la guía de preparación, que también viene dentro del material.
